# SQL Testing Project – Database Validation & Data Integrity Testing

This project showcases my practical experience in database testing using SQL queries.  
I performed data validation on a simulated e-commerce database containing intentional data issues to identify integrity violations and business logic defects.

**Scope of Testing:**
- Duplicate data detection (user email validation)
- Business rule validation (negative product pricing, zero stock active products)
- Referential integrity testing (orders linked to non-existing users)
- Data consistency checks across related tables
- Root cause analysis of data anomalies

**Deliverables included:**
- SQL Validation Queries
- SQL Test Cases
- Database Bug Reports with severity assessment
- Data validation findings documentation

**Tools & Skills Used:**
SQL | SQLite | Data Validation | Database Testing | Bug Analysis | Logical Reasoning

This project strengthened my understanding of backend data quality testing and real-world database defect identification.
